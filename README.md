Repositorio de ejercicios y prácticas realizados durante el módulo de **Desarrollo Web en Entorno Servidor** de **2º de Desarrollo de Aplicaciones Web (DAW)**.

El objetivo de este repositorio es recopilar de forma organizada los diferentes ejercicios realizados en **PHP**, aplicando progresivamente los conceptos fundamentales de la programación y del desarrollo web en entorno servidor.

---

## 📚 Contenido

Los ejercicios están organizados y numerados para facilitar su localización y seguir la evolución de los contenidos trabajados durante el módulo.

### 🔹 Fundamentos de PHP

* Variables y constantes
* Tipos de datos
* Operadores
* Entrada y salida de datos
* Conversión de tipos

### 🔹 Estructuras de control

* Condicionales `if`, `else` y `elseif`
* Condicionales anidados
* Operadores lógicos
* Bucles `while` y `for`
* Validación de datos

### 🔹 Arrays

* Arrays indexados
* Arrays asociativos
* Recorrido de arrays
* Acumuladores
* Funciones para trabajar con arrays

### 🔹 Funciones y programación

* Creación y utilización de funciones
* Parámetros y valores de retorno
* Organización y reutilización del código

### 🔹 Cadenas de texto

* Manipulación de cadenas
* Acumulación de cadenas
* Conversión y tratamiento de datos

### 🔹 Programación orientada a objetos

* Clases y objetos
* Atributos y métodos
* Encapsulación
* Creación e instanciación de objetos

### 🔹 Validación y testing

Los ejercicios incluyen diferentes pruebas con distintos conjuntos de datos para comprobar el funcionamiento de las diferentes ramas de los algoritmos y detectar posibles errores.

---

## 🗂️ Organización del repositorio

Los ejercicios se encuentran **numerados y agrupados en carpetas según el contenido trabajado**, siguiendo una estructura que permite localizar fácilmente cada práctica.

```text
ejercicios-php/
│
├── 📁 relacion1/
│
└── 📄 README.md
```

> La estructura puede ir ampliándose a medida que se incorporen nuevos ejercicios y contenidos al módulo.

## ✨ Criterios de trabajo

Los ejercicios están realizados intentando mantener unas buenas prácticas básicas de programación:

* Código limpio y estructurado.
* Comentarios cuando son necesarios para explicar la lógica.
* Nombres de variables y funciones descriptivos.
* Ejercicios numerados para facilitar su seguimiento.
* Organización por bloques de contenido.
* Pruebas con diferentes datos de entrada.
* Código orientado a que sea fácil de leer y mantener.

El objetivo no es únicamente conseguir que los ejercicios funcionen, sino **entender la lógica que hay detrás de cada solución y mejorar progresivamente la calidad del código**.
